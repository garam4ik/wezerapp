Малювання готове. Пензель активний.

Як опублікувати оновлення
  1. Натисни «Завантажити файл оновлень» — збережеться release-notes.json.
  2. Завантаж цей файл у корінь репозиторію GitHub замість старого файлу з такою самою назвою.
  3. Дочекайся завершення GitHub Pages deployment. Відвідувачам нове вікно з'явиться один раз для нової версії.

Важливо про безпеку: GitHub Pages — статичний хостинг. Цей парольний екран — лише простий бар'єр у браузері, а не справжня серверна авторизація; пароль можна знайти у вихідному коді. Не використовуй тут секретний пароль, який захищає інші акаунти. Для реального захисту потрібен зовнішній сервіс авторизації/сервер.

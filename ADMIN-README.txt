WezeraApp — проста адмінка для редагування «Що нового?»

Файли:
- admin.html / admin.css / admin.js — панель адміністратора
- release-notes.json — дані версії та список змін
- script.js — читає release-notes.json і показує модальне вікно один раз для кожної версії у браузері користувача

ПЕРШЕ НАЛАШТУВАННЯ
1. Пароль для цієї збірки: 610624. Якщо вхід не працює, переконайся, що оновив admin.js у GitHub і зроби Ctrl+F5.
2. Завантажте всі файли з папки проєкту у корінь GitHub-репозиторію, з якого публікується GitHub Pages.
3. Відкрийте https://ВАШ-САЙТ/admin.html
4. Увійдіть і відредагуйте версію та список змін.
5. Натисніть «Завантажити файл оновлень».
6. Завантажте отриманий release-notes.json у корінь репозиторію GitHub, замінивши старий файл. Дочекайтеся публікації GitHub Pages.

ВАЖЛИВЕ ОБМЕЖЕННЯ
GitHub Pages не має серверної частини. Пароль у admin.js можна прочитати у вихідному коді; він лише приховує форму в інтерфейсі та НЕ захищає від стороннього доступу. Адмінка не записує файли в GitHub автоматично. Файл release-notes.json потрібно завантажувати в репозиторій вручну. Для справжньої авторизації та автоматичного збереження потрібен зовнішній backend/auth provider або захищений workflow.

МАЛЮВАННЯ ТЕРИТОРІЙ
1. Увійди в admin.html, прокрути до карти. Пензель малює червоні ділянки, гумка стирає, скасування прибирає останній мазок.
2. Натисни «Завантажити червоні території» і завантаж red-territories.geojson у корінь GitHub-репозиторію.
3. Після публікації червоні мазки з’являться на основній карті. Це окремі мазки, не редагування адміністративних меж.
